# LabCourt v0.2.0-alpha1 Engineering Candidate — 2026-08-10

## Outcome

The alpha1 engineering path now accepts a controlled local MP4 and can reach a static operator
report through real local perception, privacy-checked evidence, a configured external VLM,
deterministic procedural review, local-only alerting, append-only human review, and restart-safe
replay.

The final operator entry point is:

```powershell
uv run --locked labcourt pilot run `
  --config configs/pilot.yaml `
  --video inputs/pilot-demo.mp4 `
  --run-id pilot-001
```

The endpoint and API key are read only from the configured environment variables. A completed run
can be repeated with the same command. Sealed perception/evidence and terminal screening authority
are reused; duplicate Cases and Alerts are not created.

## Included

- Real Grounding DINO person/goggles detection, ByteTrack anonymous in-video tracking, and pinned
  ViTPose eye localization in an isolated local worker.
- `STRICT_CAUSAL` goggles-missing candidate generation and verified real-pixel EvidencePacks.
- OpenAI-compatible Qwen screening with strict structured parsing, timeout, cache, manifest, usage,
  and raw-response authority.
- Deterministic procedural review and existing M5 closure, local alert, precedent, appeal, and
  projection authority.
- Responsive offline Chinese HTML case reports and observed `metrics.json`.
- One-command bounded backlog recovery and `REPLAY_LOCKED` restart behavior.
- Human `UPHELD` acceptance of the final engineering case, with original verdict and Alert history
  retained.

## Boundaries

This is an engineering candidate, not a production or disciplinary release. The current sample
videos are visibly AI-generated and are not ground truth. No detector/VLM accuracy, site-level
false-alert rate, throughput, or deployment-readiness claim has been established. Production alert
delivery remains disabled, reviewer identity is local and unauthenticated, and no face recognition
or cross-camera re-identification exists.

Before a real-site pilot, obtain an authorized intended-camera capture, have business/legal owners
approve the model license register, and build a human-labelled physical-camera calibration set.
Entering the B1 presence-rule scope requires a separate owner decision.
