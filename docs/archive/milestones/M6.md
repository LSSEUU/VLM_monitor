## 目标与边界

M6 把已经冻结的案件权威转化为可复现、可比较、可离线浏览的发布门禁：

```text
frozen M0–M5 authority
-> bounded dataset snapshot (stability / gold / challenge)
-> REPLAY_LOCKED | REINFER_PINNED | UPGRADE_REGRESSION
-> semantic case comparison + first divergence stage
-> regression.json
-> privacy-safe static report
-> make demo (16 named scenarios, offline fake/precomputed path)
```

本阶段不接入真实模型、GPU、摄像头或网络，不执行真实训练，也不声明真实准确率、延迟、
成本或吞吐结果。M7 模型 spike 和 M8 生产化均不进入 M6。

## 冻结规则

- 不修改 M0–M5 已导出的 wire schema、语义身份、SQLite authority 或历史投影语义；M6
  使用独立的新增契约和派生工件。
- `REPLAY_LOCKED` 复用已保存的 Detection、模型响应、embedding 与 tool result；重新执行
  确定性领域逻辑、L5、策略和报告。它不得调用 provider，也不得读取当前判例/标签尾部替换
  历史 causal cut。
- `semantic_case_hash` 排除 run ID、墙钟、发送回执时间、本机路径和性能/成本等运维字段，
  但保留事件帧、证据内容 hash、模型响应引用、裁决、缺陷、策略和 manifest。
- `REINFER_PINNED` 必须固定完整 manifest，并把结构、裁决和引用差异显式写入报告；差异本身
  不自动判为缺陷。默认验收只使用可离线 fake provider。
- `UPGRADE_REGRESSION` 比较 baseline/candidate manifest。stability set 的机器方向翻转率不得
  超过配置阈值；gold set 的正确率不得下降；任何 emergency 退化都必须标记人工复核。
- 原始申诉案件必须进入 gold set，不得仅从 stability gate 排除；弱标签不得冒充 gold truth。
- 每个翻转案件必须列出首个分歧层：`PERCEPTION`、`SCREENING`、`RETRIEVAL`、
  `HEARING`、`GATE` 或 `POLICY`。汇总数字必须能从逐案结果重新计算，伪造统计 fail closed。
- `regression.json`、dataset snapshot 与 HTML 都是内容校验的派生工件；发布必须原子化，失败
  转为类型化退出，不留下被误认为成功的半成品。
- 静态报告只展示持久化的隐私处理版本；retention 已删除的证据显示占位和删除审计，不读取
  原始图像，不展示模型隐藏推理。
- 所有输入扫描、JSON/SQLite 读取、报告大小和场景数量必须有显式上限；默认路径无网络、无 GPU。
