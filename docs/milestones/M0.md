# M0：工程骨架与契约

状态：已验收并冻结为后续里程碑基线。

## 范围

- Python/uv 工程与离线质量门。
- Pydantic v2 公共契约、配置和静态违规注册表。
- LCJ-1 canonical JSON、精确帧时间与确定性 ID。
- 能力端口、schema export/check、八个最小 fixture。
- 本地工作区、匿名引用、模型媒体请求和缓存键的安全边界。

## 验收

```text
mingw32-make format-check
mingw32-make lint
mingw32-make typecheck
mingw32-make test
mingw32-make e2e
mingw32-make schemas-check
```

Linux/macOS 环境可把 `mingw32-make` 替换为 `make`。

当前离线门禁覆盖 Pydantic 与 Draft 2020-12 双重校验、八个 fixture 的跨引用闭合、
主动断网哨兵、端口签名、严格类型、确定性 ID 和隐私边界。详细边界见
[`docs/security-boundaries.md`](../security-boundaries.md)。

## 本里程碑不适用

SQLite migration、运行工件 validator、业务 `semantic_case_hash` 重放、HTML 报告、隐私裁切
像素验证和 16 个完整业务场景分别属于 M2–M6；M0 不以空实现伪装这些能力。
JSON Schema 不能独立替代 Python artifact validator；文件实体、symlink/junction containment
和物理 SHA-256 闭合在 M2 实现。
