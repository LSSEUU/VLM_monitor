## M8.3b2 状态转换与 manifest 影响

`commit_poll_result` 不改变案件状态，只把一个 exact adapter result 从内存变成 durable cache。新 poll 在
同一 SQLite 事务写入 raw BLOB、sample receipts、cache receipt 与 links；任一 hash、目录、sequence、
manifest 或 link 冲突会整体回滚。receipt 绑定 source/adapter/catalog/raw-storage/cache/repository manifest，

显式 application workflow，持久化 sample 本身不产生处分、消防或生命安全联动。
