# M1：确定性感知核心

状态：实现完成。

## 范围

- `SyntheticFrameSource` 与严格 UTF-8 的 `PrecomputedFrameSource`，仅使用本地、内存媒体引用。
- 人体脚点分区、闭边界多边形判定、PPE 关键点锚区与人体框回退关联。
- 六分量可观测性评分；评分仅用于选帧和证据充分性，不参与触发门控。
- 存在型与缺失型逐轨迹状态机、精确有理数 FPS 换算和确定性事件 ID。
- `STRICT_CAUSAL` 缺失确认；`SOURCE_COMPAT` 仅在显式启用的离线实验模式可用。
- 无身份、无持久化能力的 L0 软提醒及内存冷却。
- 经认证的硬安全直连路由；视频启发式只能降级为非硬候选事件。
- 关联结果、可观测性结果与匿名提醒的版本化 JSON Schema。

## 关键语义

- 缺失型涉嫌区间固定为 `[absence_start, threshold_frame_exclusive)`。
- 只有绑定到该区间帧且模型 manifest 一致的晚到正检可以抑制历史区间。
- 阈值后的首次补戴只记录 `post_threshold_recovery_frame_id` 和 `resolved_frame`，
  不撤销已经发生的历史区间。
- 轨迹引用只表示单摄像头内 tracker 连续性，不表示真实身份，也不会跨摄像头拼接。
- 可观测性再低也不能阻止候选触发；它只影响后续证据选择和程序充分性。
- L0 服务没有文件、数据库或审计写入接口，返回值也不包含 `track_ref`。

专项覆盖规格 §9.7 的十类边界：连续计时与中断、非整数 FPS、几何越界、锚区回退、
低可观测性不门控、区间内晚到反证、阈值后补戴、轨迹切换、确定性重放，以及未认证视频
不得发硬告警。集成测试同时检查 L0 运行前后目录完全不变。

## 本里程碑不声称

预计算 fixture 不代表真实摄像头、检测器、跟踪器或 PPE 准确率，也不构成任何性能验收。
视频解码、像素裁切、隐私变换、实体文件哈希、EvidencePack 闭包和 SQLite 审计属于 M2。
