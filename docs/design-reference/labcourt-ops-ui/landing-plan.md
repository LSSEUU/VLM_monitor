# LabCourt 落地首页 · 内容与结构规划

> 用途：项目的"脸"——评委/访客的第一屏。一条滚动叙事的宣传页，承载立意、功能切片、伦理立场、入口。
> 风格已锁：编辑刊物 → 电影化（沿用 DESIGN.md tokens）；视差 + 滚动驱动"纸白→朱砂"色彩迁移 + 功能切片复用已有画面。

## 受众与目标
- 受众：评委、校内师生、潜在合作方。
- 主目标：30 秒内让人 get 到"AI 看着实验室 + 人在环 + 伦理"这一差异化，并点进监控/案件页。
- 转化：一个主 CTA（进入监控），其余为锚点/次要链接。

## 文件名
- `landing.html`（语义清晰，不扰动现有各页 brand 链接）。或作 `index.html`（当根 front-door）——待定。
- [ ] 文件名定哪个？

## 视觉系统（复用 + 新增）
- 复用 `DESIGN.md` tokens + Source Serif 4 / 思源宋体 + IBM Plex Mono；可选挂 `assets/nav.css` 的极简 landing-header（或独立的页眉）。
- **滚动色彩迁移**：一层 fixed 背景，顶部纸白 → 向下渐入影院墨/朱砂（编辑→电影），呼应整套语言；不滥用渐变。
- **视差**：Hero 用 `assets/feed-301a.mp4` 做背景视频 + 识别框叠层，前景文案视差更快（transform-based，非 background-attachment，避免抖动）。
- **动效母题**：clip-path 擦除（标题/分隔）+ IntersectionObserver 区块淡入上移；唯一一种擦除，全场统一。

## 页面层级（分屏 + 文案草案）

### 1 · Hero（全屏）
- 背景视频 + 识别框叠层 + 视差。
- 立意标题（衬线大字）候选：
  - A：「让实验室安全，看得见、说得清、靠得住。」
  - B：「AI 看见，人做决定。」
  - C：「实验室的每一秒，都在被认真看着。」
- 副标题：LabCourt 用视觉大模型与传感器持续守护校园实验室——识别风险、结构化取证、人在环裁决；不做人脸识别，AI 不自动定责。
- 主 CTA：进入监控 →（monitor.html）；次：了解审理流程（锚点 #features）。
- [ ] 标题选 A/B/C 还是另写？

### 2 · 现状 / 痛点
- 一句：人防有盲区、事后追溯难、合规压力大。
- 短段（≤3 行）：传统监控只录像、不"看懂"；出事才翻带子。

### 3 · 解法 / 立意（3 原则）
- 识别：视觉大模型看懂现场（PPE / 行为 / 区域），不只是录像。
- 伦理：不做人脸识别、AI 仅建议、可申诉。
- 裁决：控辩会审 + 程序守门 + 人工盖章。

### 4 · 功能切片（Feature slices，复用真画面）
- 监控：视频 + 识别标注（用 feed 视频 + 模拟框）。
- 时间轴：色块回溯历史识别/案件。
- 案件卷宗：控辩会审 + 流程进度。
- 设备联动：传感器实时值 + sparkline。
- 每片 = 一张"剧照"卡 + 一句 caption；滚动错峰浮入。

### 5 · 伦理立场（色彩迁移的朱砂高潮段）
- 不做人脸识别 · AI 仅提议 · 可申诉 · 人在环。
- 段落 + 一枚"盖章"图形（呼应案件页的盖章动作）。

### 6 · 数字 / 证据（诚实）
- 在线机位 04/04 · 今日候选 07 · 处理链 6/6 通过。
- 全部标"示例/模拟"，不编造真实统计。

### 7 · CTA / 页脚
- 主：进入监控 →（monitor.html）；次：查看案件审理 →（case-file.html）。
- 页脚：团队/项目信息占位、海南大学·信通学院、PREVIEW 标记。
