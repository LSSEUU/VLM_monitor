## Completed

- Added the optional, backward-compatible `PilotConfig` contract and generated schemas.
- Added the content-bound `PilotRunRequest` command contract.
- Added `labcourt pilot run`, `perceive`, `report`, and `review` command boundaries.
- `run` and `perceive` now perform a fail-closed preflight over a workspace-relative MP4,
  portable run identity, pilot config, secure workspace handles, and video SHA-256.
- A0 preflight does not create a run and does not call a detector or VLM.
- Later-stage report/review commands fail explicitly until A4 instead of fabricating results.
- Added a pilot config sample and Git exclusions for real videos, secrets, and model weights.
- Added contract and CLI scenario coverage for safe success and rejected input boundaries.
- Added a versioned, bounded JSONL subprocess protocol that binds every request and response
  to `frame_id`, LCPIX1 pixel SHA-256, model manifest, and strict byte/time limits.
- Added pinned offline Grounding DINO Tiny inference and Roboflow ByteTrack tracking in an
  isolated `.venv-perception` environment; the core environment still has no model dependency.
- Added explicit worker startup, timeout, crash, malformed response, model failure, tracker
  failure, and frame-identity mismatch states. Empty detections are successful only when the
  worker explicitly returns `SUCCEEDED`.
- Added deterministic first-observation ByteTrack ID activation, camera-scoped anonymous
  `track_ref`, and mapping onto the existing `Detection` and `FrameBundle` contracts.
- Added per-frame raw-response files, immutable response receipts, replay-aware cache behavior,
  exact model/weight/runtime manifests, and completed-run resume without another model call.
- Added a last-written, content-derived A1 completion manifest. Resume now verifies the exact
  ordered artifact inventory, sizes, SHA-256 values, FrameBundle/receipt/raw-response identities,
  derived detections, aggregate counts, and optional preview before accepting a completed run.
- Added fail-closed recovery scenarios for missing sealed FrameBundles, raw responses, and preview;
  a legacy or interrupted run without a completion seal is rebuilt from cached responses and then
  sealed instead of being mistaken for complete.
- Added caller-attested, securely probed CFR `StreamManifest` construction and reuse of the
  existing two-pass hash-validating `OpenCvVideoSource`.
- Added optional non-authoritative `runs/<run_id>/debug/perception-preview.mp4` generation and
  immutable A1 report, execution manifest, video manifest, receipts, and FrameBundle JSONL.
- Added an idempotent PowerShell setup script for the CUDA worker and updated the model license
  register with exact source revisions, weight digest, obligations, and pending business review.
- Ran an actual CUDA smoke on a two-frame geometric MP4: real Grounding DINO + ByteTrack returned
  3 detections, one anonymous track, zero provider failures, and a debug preview. This is a
  pipeline check only, not an accuracy, latency, throughput, or cost evaluation.

## Known Limitations

- A1 has not been visually accepted on authorized laboratory footage. The geometric smoke
  intentionally cannot establish real-site detector quality and produced semantically meaningless
  model labels, which are not treated as ground truth.
- Pilot stream timing is a caller-attested CFR declaration derived from bounded decoder metadata;
  variable-frame-rate source files require normalization or a future trusted timing sidecar.
- The preview is a non-authoritative debugging artifact and may contain people from the selected
  local input. It remains under the ignored local `runs/` boundary.
- `report` and `review` are discoverable but return `STAGE_NOT_AVAILABLE` until A4.
- Only `PPE_GOGGLES_MISSING` is accepted for the alpha1 pilot; the presence rule remains B1.
- No accuracy, latency, throughput, or cost claim has been made.
