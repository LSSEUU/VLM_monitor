# LabCourt · DESIGN.md（锁定 token 契约）

> **calm**（编辑刊物 · 默认纸态）/ **alarm**（受控朱砂层 · 不切换全局主题）。
> 所有颜色为 OKLch 派生，不抄任何品牌 hex。气质灵感：Runway / Sanity / Claude / GOV.UK + 编辑刊物方向。

## 立意（一句话）
一份关于实验室安全事件的"编辑卷宗"——纸态始终克制；告警不整屏翻暗，只用一道受控的朱砂（横幅 + 帧级锁定）把最致命的一刻指出来。

## 双态 token

### calm（默认）
| token | 值 | 角色 |
|---|---|---|
| `--bg` | `oklch(0.965 0.006 85)` | 暖纸白 |
| `--surface` | `oklch(0.99 0.004 85)` | 卡片/证据板 |
| `--fg` | `oklch(0.22 0.01 60)` | 墨（正文） |
| `--muted` | `oklch(0.46 0.012 60)` | 次要文字 |
| `--border` | `oklch(0.88 0.006 75)` | 发丝线 |
| `--accent` | `oklch(0.45 0.09 250)` | 墨蓝（极少，≤2 次/屏） |

### alarm（受控朱砂层 · 非全局主题切换）
**告警不改 calm 的 bg/fg/surface/border——页面始终保持纸态。** 告警 = 叠加一层朱砂：

| token | 值 | 角色 |
|---|---|---|
| `--alarm` | `oklch(0.50 0.15 28)` | **朱砂（告警态唯一彩色，更深更可控）** |
| `--alarm-ink` | `oklch(0.985 0.02 30)` | 朱砂底上的纸色文字 |

朱砂只出现在：① 顶部告警横幅（满宽，可忽略、可跳转监控）② 相关证据帧的锁定角括号 + 扫描线 ③ 顶栏底线。**绝不整屏铺满、不翻转明暗。**

## 字体（2 族）
- `--font-serif`: `"Source Serif 4", "Noto Serif SC", "Songti SC", Georgia, serif` —— 标题 + 正文（刊物感）
- `--font-mono`: `"IBM Plex Mono", "JetBrains Mono", ui-monospace, monospace` —— 眉标 / 数据 / 案号 / 时间戳 / UI 控件（取证感）

## 排版守则（craft，不可破）
- CJK 标题行高 `1.3–1.4`、正文 `1.7–1.8`；**中文不做负字距**；ALL CAPS 正字距 `≥0.06em`。
- 正文行宽 `≤65ch`。
- 每屏 `--accent` `≤2` 次；alarm 朱砂是唯一彩色，**仅在告警态出现**（对比即设计）。

## 动效原则
克制。calm：匿名轨迹点 + AI 注意力光晕做极慢呼吸。alarm：顶栏底线转朱砂 + 横幅滑入 + 相关帧的朱砂锁定/扫描手势（帧级，非整屏）。提供 `prefers-reduced-motion` 兜底。

## 伦理红线（继承 README）
不做人脸识别、AI 不自动定责、引用必带来源；画面用匿名轨迹 / 抽象合成场景，绝不展示真实人脸或授权录像。
