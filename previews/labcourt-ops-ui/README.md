# LabCourt 校园实验室安全运营平台 · UI 风格预览

这是一个与现有 pilot UI、后端契约和真实接口完全隔离的纯前端样板。

- 所有画面、案件、传感器和通知数据均为 `PREVIEW / SIMULATED`。
- 不包含人脸识别、跨摄像头 ReID 或真实人员身份。
- AI 只展示结构化建议、证据引用和简洁理由，不展示隐藏思维链，也不直接定责。
- “紧急事件”由模拟传感器信号触发，仅用于演示界面层级。
- 页面不发送网络请求，不执行生产告警或纪律动作。

使用任意静态文件服务器打开本目录即可，例如：

```powershell
python -m http.server 4173 --directory previews/labcourt-ops-ui
```

然后访问 `http://127.0.0.1:4173/`。
